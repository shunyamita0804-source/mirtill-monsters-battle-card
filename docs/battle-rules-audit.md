## 2. 最小設計（案・未実装）

### カードの型

```ts
type CardKind = 'monster' | 'skill' | 'support';

/** 誰が使えるか */
type Compat =
  | { type: 'monster'; ids: string[] }          // 特定モンスター
  | { type: 'common' }                          // 全モンスター共通技
  | { type: 'breed'; main?: string; sub?: string }; // 派生種（要確認）

interface SkillCard {      // 技（攻撃・防御・回避・特殊技）
  kind: 'skill';
  compat: Compat;
  cost: number;            // マナ
  role: 'attack' | 'defense' | 'evade';
  stat?: { type: 'force' | 'wisdom'; value: number };
  tags: ('special' | 'unblockable' | 'undodgeable')[];
  effects: Effect[];
}

interface SupportCard {    // 旧ブリーダー・全体カードもここ
  kind: 'support';
  cost: number;
  timing: 'action' | 'response' | 'mana';        // いつ使えるか
  duration: 'instant' | 'field';                  // 即時／場に継続
  target: 'self' | 'opponent' | 'both' | 'ally1' | 'enemy1' | 'allAlly' | 'allEnemy';
  limit?: { per: 'turn' | 'battle'; count: number };  // 使用回数（効果ごとに設定）
  field?: { slot: string; until: 'turns' | 'replaced'; turns?: number };  // 場の上書き
  effects: Effect[];
}
```

### バトルの状態とフェーズ

```ts
type Phase = 'draw' | 'action' | 'defense' | 'mana' | 'end' | 'ended';

interface BattleSide {
  deck: string[]; hand: HandCard[]; discard: string[];
  manaPile: string[];   // マナ化したカード（積んだ順）。マナ＝枚数。上限なし
  field: FieldEffect[]; // 場に継続する効果
  usage: Record<string, number>; // 回数制限の記録
}
```

- 進行：ドロー（5枚まで。足りなければ敗北／5枚なら山札トップをマナ化）→ 攻撃（1体1技）→ 守備（相手が0〜n枚）→ 解決 → マナ化（任意枚数）→ 終了
- 解決順（仮の枠。順番は要確認）：攻撃値 → 場の補正 → 回避 → 軽減・無効 → ダメージ → 反射 → KO判定 → 勝敗判定（同時KOの扱いは要確認）
- 支払い：`manaPile` から必要枚数を取り除いて捨て札へ。効果で減らす・山札へ戻す処理も同じ入口を通す
- AI も同じ `applyAction` だけを使う（今の構造を維持）
