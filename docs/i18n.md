# 日本語・英語の切り替え（i18n）のしくみ

2026-10-22 導入。対応言語は日本語（ja・初期値）と英語（en）。設定画面で切り替え、言語だけの設定として保存する（セーブデータとは別）。

## 決まり

| 何を | どこに | 引き方 |
| --- | --- | --- |
| 画面の固定の文字（ボタン・見出し・お知らせ・エラー・バトルの記録など） | `src/i18n/messages/<分野>.ts`（キー → `{ ja, en }`） | `t('分野.用途', { n: 3 })` |
| data/ の固有名・説明（カード名・パック・大会・相手・ダンジョン・マップ・扉や家具の名前） | 日本語は `src/data/` の値のまま。英語は `src/i18n/contentEn.ts`（`種類:ID:項目` → 英語） | `cardName(card)`・`packName(p)`・`objectLabel(o)` など（`src/i18n/content.ts`） |
| 能力・レアリティ・分類・効果の名前、技とサポートの説明 | `src/i18n/messages/cards.ts` | `statLabel()`・`rarityLabel()`・`kindLabel()`・`effectLabel()`・`describeSkill()` など（`src/game/cards/cardTypes.ts`） |

- 数値は文字列の連結ではなく `{name}` で埋める：`t('battle.damage', { name, n })` ← `'{name}に{n}ダメージ。'`
- 英語の単数・複数は `{n|card|cards}`（n が 1 なら左）。日本語では使わない
- 英語が空・辞書にないキーは日本語に戻す。組み立てたキーは `tKey()`（なければ fallback）
- カードの ID・数値・勝敗は翻訳と切り離す。翻訳は表示するときだけ
- 公式画像に英語を焼き込まない。技カードの文字・数字はこれまでどおりコードで描く
- `<html lang>` と画面のタブの題名（`document.title`）は言語に合わせて変わる（`src/ui/app.ts`）
- PWA のアプリ名（manifest）は日本語の正式名称のまま（言語ごとのホーム画面名は作らない）
- バトル中は言語を変えられない（設定画面はバトルから行けない）。言語を変えても進行・手札・マナは変わらない

## テスト（`tests/i18n.test.ts`）

- すべてのキーに ja と en がある・空でない
- ja と en でプレースホルダーが同じ
- 同じキーが2つの分野にない
- 長い同じ日本語文が2つのキーにない（短い語は除く）
- data/ の固有名に英語があるか（ないものは一覧を出す。仮データの英語は仮訳）

## 英語名が未決のもの

カード・パック・大会・ダンジョン・マップはすべて仮データのため、英語はすべて**仮訳**（正式な英語名は未決）。
仮カードの英語名は「Temp …」（日本語の「仮」にあたる）。隠しモンスターは「??? (Hidden monster, TBD)」。
能力名の英語（ちから＝POW、かしこさ＝INT）も仮訳。
