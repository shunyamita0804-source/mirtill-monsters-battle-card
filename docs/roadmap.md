# 開発段階

各段階の完了後はユーザーの承認を得てから次の段階に進みます。自動での段階移行はしません。

| 段階 | 内容 | 状態 |
| --- | --- | --- |
| 第1段階 | 新規独立開発環境の構築（リポジトリ・Vite・TypeScript・Vitest・assets・Pages準備） | 完了・承認済み（[報告](phase-1-report.md)） |
| 第2段階以降 | ゲーム画面、カードバトルシステム、モンスターカード、技カード、街マップ、ダンジョン、ガチャ、大会、正式素材の組み込み、GitHub Pages 公開 | 第2段階の指示書待ち |

第2段階以降の具体的な分け方は、第1段階の承認時に決めます。
