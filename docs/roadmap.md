# 開発段階

各段階の完了後はユーザーの承認を得てから次の段階に進みます。自動での段階移行はしません。

| 段階 | 内容 | 状態 |
| --- | --- | --- |
| 第1段階 | 新規独立開発環境の構築（リポジトリ・Vite・TypeScript・Vitest・assets・Pages準備） | 完了・承認済み（[報告](phase-1-report.md)） |
| 第2段階 | スマホ向けゲーム基盤（画面拡大縮小・セーフエリア、4画面の遷移、カードバトル画面の基盤） | 実装済み・承認待ち（[報告](phase-2-report.md)） |
| 第3段階以降 | カードバトルシステム、モンスターカード、技カード、街マップ、ダンジョン、ガチャ、大会、正式素材の組み込み、GitHub Pages 公開 | 未着手（指示書待ち） |

第3段階以降の具体的な分け方は、ユーザーの指示書で決まります。
