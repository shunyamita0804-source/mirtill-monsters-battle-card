・ユーザーの感想（2026-10-24）：プログラムで部品を動かす試作は「ロボットみたい」。人間がしっかり歩いているようにしたい
・人が歩いて見えるいちばんの理由は「体重の上下」：足が着いた直後に体がいちばん沈み、片足で立ち上がるときにいちばん高くなる。
  その途中で、服のすそ・髪・かばんが少し遅れてついてくる。これは絵で描くしかない
・前の依頼（Seimon_Motion_Walk_Run）は1歩2コマ（足を着く・足を運ぶ）だった。この第2版は、アニメーションの基本どおり1歩4コマにする
　足を着く → 沈む → 足を運ぶ → 伸び上がる（右足の1歩）→ 同じ4つを左足で ＝ 1周8コマ
・走りも1歩4コマ：着地 → 沈む → けり出す → 浮く ＝ 1周8コマ
・前の依頼で届いた絵（正面の「足を運ぶ」）も見本として添付する。そろわなくても大丈夫（全部この第2版で描く）
・前の依頼（Seimon_Motion_Walk_Run・Seimon_WalkPassing）は、この第2版に置きかえる
