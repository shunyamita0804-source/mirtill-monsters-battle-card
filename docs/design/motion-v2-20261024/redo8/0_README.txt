歩きの絵の依頼（作り直し・1枚に8ポーズ）2026-10-24

前回は「1歩ずつ2枚」に分けて頼んだところ、2枚目が1枚目とほぼ同じ絵になった。
今回は1周分（8ポーズ）を1枚に、上の段（右足の1歩）・下の段（左足の1歩）で描いてもらう。

■ やりかた（left・back それぞれ）
1. 画像AIで「新しい会話」を始める（前の会話の続きにしない。前の絵をまねてしまうため）
2. 1_ 2_ 3_ の画像3枚を添付し、4_PROMPT の文をそのまま貼って送る
3. 下の段が上の段と同じ形になっていたら、同じ会話で 5_IF_SAME の文を貼る
4. できた絵を Claude に送る

■ left（左向き）＝必須。右向きは左向きを Claude が反転して作る
■ back（背中）＝おすすめ。いまは Claude が1枚目から足だけ入れ替えて作った仮の絵が入っている。描いてもらえれば、腕の振り・すその揺れも自然になる

■ 受け取ったら（Claude）
上の段・下の段を 1536×512 ずつに切って motion-v2/player_male_{left,back}_walk_r.png（上）・_l.png（下）に置き、adult_walk_build.py で作り直す。
動きの見本は tools/art/walk_guide_draw.py（guide8_*.png）で作る
