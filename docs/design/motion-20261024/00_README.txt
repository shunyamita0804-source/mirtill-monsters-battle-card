■ 目的
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
・ユーザーの試遊（2026-10-24）：「動きがチープ」「斜めの歩行も腕の振りや足が微妙」「自然に歩いている・走っているように仕上げたい。販売するのでクオリティを上げる」
・いまの歩きの絵は「右足を前・立つ・左足を前」の3ポーズだけで、走る絵は無い（歩きの絵を速く動かしている）
・この依頼で、主人公（男性・女性）の 歩き4ポーズ＋走り4ポーズ を、5つの向きでそろえる
　（右・右下・右上は Claude が左・左下・左上を左右反転して作るので、全部で8方向になる）
・この依頼は、前に渡した「足を運ぶ途中」の依頼（Seimon_WalkPassing）を含む。こちらを使えばよい
　（すでにそちらで作った絵があれば、その絵も送ってほしい。そのまま使う）

■ 1歩・1回の動き（ゲームではこの順にくり返す）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
歩き：W1 右足を前に着く → W2 右足で立ち、左足を運ぶ → W3 左足を前に着く → W4 左足で立ち、右足を運ぶ
走り：R1 右足で着地 → R2 浮く（左ひざが前へ） → R3 左足で着地 → R4 浮く（右ひざが前へ）
