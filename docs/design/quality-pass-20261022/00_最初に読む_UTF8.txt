■ なぜ追加の絵が必要か（試遊動画で見えた問題のうち、絵がないと直せないもの）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
プログラムで直せるもの（画面いっぱいの表示・場所を移るときの暗転・人物の影・草地の色むら・道のふち・
小物を増やす・上の帯や看板の見た目）は、Claude がすでに直しました。
次のものは「絵そのもの」が足りない・弱いので、デザイン担当の新しい絵が必要です。

　1. 店や施設に人がいない（店員・研究員・受付・先生・住人の絵がない）→ 街が無人で寂しい
　2. 草地・道のわきの小物（植え込み・岩）が平たく見え、安っぽい。草地の細かい飾り（草むら・小花）がない
　3. 道のふち（縁石）と広場の模様がなく、石畳がただの四角に見える
　4. 部屋の絵が正方形なので、縦長のスマホでは上下が大きく空く
　5. 上の帯・看板・ボタンなどの UI に、ゲーム専用の絵がない（いまは CSS で作った仮の見た目）
　6. ダンジョンは色の四角だけの仮マップ（床・壁・階段・宝箱・敵の絵がない）
　7. （任意）斜めに歩くときの絵がない（いまは左右の絵で代用）

これから、スマホ向け2Dカードゲーム「セイクリッドモンスターズ バトルカード」の素材を1つずつ描いてもらいます。
このゲームは販売する商品です。どの素材も、市販のスマホRPGと並べて見劣りしない品質で描いてください。
【画風】
・添付の画風見本・人物の絵と同じ画風・色合い・描き込みの細かさにそろえる（やわらかい手描き風の高精細ドット絵調）
・視点は「斜め上から見下ろす正面の視点」。光は左上から。影は右下に落ちる
・輪郭はくっきり、色はあざやかすぎず、街の絵になじむ明るさ
【禁止】
・文字・数字・ロゴ・透かし・サイン
・実在の作品・ゲームのキャラクターや紋章に似せること
・依頼していない物（人・動物・地面・背景・枠）を足すこと
【形式】
・背景は透明（できなければマゼンタ一色 #FF00FF）
・素材の外側に余白を少し（上下左右 4% くらい）。素材どうしは重ねない
