■ なぜ何回直しても自然にならなかったか（結論）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 速さと絵の歩幅が合っていない（いちばん大きい）
   ゲームの主人公は、実際の人の約3倍の速さで歩く（街を早く移動するための設定）。ふつうの歩幅の絵をこの速さで動かすと、
   足を速く回せば「パタパタ」、ゆっくり回せば「足が地面をすべる」。どちらかにしかならない。絵を直しても消えない
2. 走りの絵が無い
   走るときも歩きの絵を 1.6 倍速で回している。走りは別の動き（前傾・ひざ・けり出し・両足が浮く）で、絵が無いと走って見えない
3. 画像AIの失敗（2枚目が1枚目と同じ・足の左右の取り違え）
   向き×動作を増やすほど失敗が増える。いまは斜め4方向が「3ポーズ」のまま品質を下げている

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 決めごと（この3つで進める。変えたいときは Claude に一言）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
A. 歩きは「大股の速足」として描く：着く瞬間の前後の足の幅（かかと〜かかと）＝ 身長の 0.6（枠の中で約 200px）
   → ゲームの速さは変えない。絵が届いたら Claude が歩幅を測り、ゲームの1歩の長さを絵に合わせる（足滑りが消える）
B. 走りは別の8コマを描く：かかと〜かかと ＝ 身長の 1.0（約 330px）。前傾・両足が浮くコマあり
C. 歩き・走りの絵は4方向（正面・背中・左。右は左の反転）。斜めは横の絵で代用する
   → 枚数が半分になり、失敗が減る。斜めの専用の絵は、4方向が全部そろってから考える

■ 頼む順番（1枚できるごとに Claude へ。Claude が組み込んで動画を返す）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 1枚の頼み方（毎回同じ）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 画像AIで「新しい会話」を始める（前の会話の続きにしない。前の絵をまねして同じ絵になるため）
2. そのフォルダの 1_（参考）・2_（枠）・3_（動きの見本。歩きは _walk、走りは _run）の3枚を添付
3. 4_ か 5_ の文をそのまま貼って送る
4. できた絵を見て
   ・上下の段が同じ形 → 同じ会話で 6_IF_SAME の文を貼る
   ・足が逆・腕が振れていない・大きさが違う など → 7_FIX の中の当てはまる一言を貼る
   ・2回直しても良くならない → その絵のまま Claude に送る（ひざ下の反転・大きさ合わせなど、Claude が直せることが多い）
5. 1536×1024 の PNG で保存して Claude に送る（名前：player_male_left_walk8.png のように 人物_向き_動作8）

■ それでもうまくいかないとき
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
・画像AIは「同じ人物で8つの違うポーズ」が苦手。3回頼んで2回失敗するのはふつう。1枚に8ポーズ＋動きの見本＋新しい会話、が
  いままででいちばん成功した形（正面の歩きはこれで通った）
・人に頼む選択肢：この一式（枠・動きの見本・参考画像・仕様）をそのまま渡せば、2Dアニメが描ける人なら迷わず描ける。
  クラウドソーシング（ココナラ・スキマ等）で「ゲーム用 歩行・走行 スプライト 8コマ×5枚（1人）」。目安 3〜8万円／1人。
  時間と手間を考えると、男性の左向きで画像AIを2回試してだめなら、人に頼むほうが早い
・Claude ができること：届いた絵の大きさ・足元・体の中心をそろえる、ひざ下だけの左右反転、ズボンと靴だけの入れ替え、
  1枚から足りないコマの合成（背中のように）。ただし合成は「腕が振れない」など限界がある

■ Claude がすること（届いたら）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
・上下の段に切って、大きさと足元をそろえ、ゲームの1枚にまとめる（体の上下は絵のとおり残す）
・確認画面（?qa=1&lab=walk）で歩幅を測り、ゲームの1歩の長さを絵に合わせる（足滑りを消す）
・走りの絵は、ゲームに走りの行を足して、走りの速さ・足音・切り替えの位相を合わせる
・前の歩きと並べた動画で確認してもらう

■ このフォルダ
left/   男性・左向き：参考・枠・動きの見本（歩き・走り）・文（歩き 4_・走り 5_・同じ形のとき 6_・直しの一言 7_）
back/   男性・背中：同じ構成
front/  男性・正面：走りだけ（文 5_・動きの見本は横から見た図）
