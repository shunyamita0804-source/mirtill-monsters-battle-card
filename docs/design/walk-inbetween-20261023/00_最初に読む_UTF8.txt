■ なぜ頼むか
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
・街を歩くときの「カクカク」は2つの原因が重なっている
　① 1マス進むごとに画面が1コマ止まっていた → ゲーム側で直した（作業ブランチ fix/smooth-walk）
　② 足の動きの絵が少ない → この依頼で直す
・いまの歩きの絵は「立つ・右足を前・左足を前」の3ポーズだけ。これを
　「立つ → 右足を前 → 立つ → 左足を前」と並べ、1秒に約13回切り替えている。
　ポーズの差が大きいので、足が「パタパタ」と飛ぶように見える
・あいだに「半歩」のポーズを2つ足すと、1歩が4コマ→8コマになり、足が途中を通って動くので滑らかになる
　立つ → 右足を半歩 → 右足を前 → 右足を半歩 → 立つ → 左足を半歩 → 左足を前 → 左足を半歩 → （くり返し）

■ 頼むもの
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1人につき3枚（正面・背中・左向き）。1枚に3ポーズ：「1 右足を半歩前」「2 立つ（見本）」「3 左足を半歩前」
・真ん中の「立つ」は、大きさをそろえるための見本（ゲームでは前の絵の「立つ」を使う）
・右向きは Claude が左向きを左右反転して作る

おすすめの順番：
1. まず主人公（男性）の正面1枚だけ作って Claude に送る
   → Claude がゲームに入れ、いまの歩きと並べた動画・画像を返す。よければ続きへ
2. 主人公（男性）の背中・左向き → 主人公（女性）の3枚
3. ほかの人は、街を歩き回らないので後回しでよい（案内役が先に立って歩く動きを作るときに案内役の3枚）

■ 注意（うまくいかないとき）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
・新しく描いた絵が前の絵と少しでも違う（顔・服の模様・色・大きさ）と、歩くたびに絵がちらついて、かえって見づらくなる。
　そのときは Claude が比べて「使える／使えない」を判断し、使えなければ今の4コマのままにする
・いちばん大事なのは、前に作った歩きの絵（○○_walk_front.png など）を毎回添付すること
