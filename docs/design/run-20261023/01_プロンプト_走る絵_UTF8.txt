■ なぜ頼むか
・2026-10-23 に「スティックを大きく倒すと走る」をゲームに入れた。走る絵がまだ無いので、いまは歩きの絵を大きな歩幅で動かしている（速歩きに見える）
・走る絵が届いたら、走るときだけその絵に切り替える。並べ方は「右足を前 → 浮く → 左足を前 → 浮く」の4コマ（Claude が作る）
・右向きは Claude が左向きを左右反転して作る

■ 頼む順番
1. まず主人公（男性）の正面1枚 → Claude がゲームに入れて動画で返す → よければ残り
2. 主人公（男性）の背中・左向き → 主人公（女性）の3枚
・走るのは主人公だけなので、ほかの人の分はいらない

■ 添付するもの（1枚ごと）

添付の「歩きの絵（3ポーズ）」は、すでにゲームで使っている同じ人物の絵です。この人物が走る絵を描きます。

【描くもの】横長 1536×1024。添付の枠のとおり、横に3つ並べる。
・1 走る・右足を大きく前：右足を大きく前に出し、左足は後ろへ大きくけり出す。左腕を前、右腕を後ろに大きく振る
・2 走る・両足が浮く：両足が地面から少し離れた瞬間。足は体の下で軽く曲げる。体はいちばん高い位置
・3 走る・左足を大きく前：1 の左右逆。左足を大きく前、右足を後ろ。右腕を前、左腕を後ろ
・3つとも、体を少し前に傾ける。ひじは曲げる。歩きの絵より足の開きと腕の振りをはっきり大きく
・髪や服のすそ、かばんが、走る勢いで少し後ろへなびく

【いちばん大事なこと】
・添付の歩きの絵と、まったく同じ人物・同じ絵。顔・髪型・帽子・服の模様・飾り・持ち物・色・線の太さ・塗り方を変えない
・同じ頭身・同じ大きさ。頭の上と足元を枠の線にそろえる（2 は足元より少し上に浮かせてよい）。体の中心は点線

【画風】添付の絵と同じ。筆で塗り重ねた手描きの質感。輪郭は濃い茶色系の線。ベクター風・フラット・3DCG風は禁止
【禁止】文字・数字・ロゴ・透かし・サイン。地面・影・砂ぼこり・動きの線・背景・枠の線と文字・ほかの人物。3人が重ならない
【形式】背景は透明（できなければマゼンタ一色 #FF00FF）。PNG
