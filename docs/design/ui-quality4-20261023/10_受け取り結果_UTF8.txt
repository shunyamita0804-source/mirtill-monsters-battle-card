デザイン第4弾10枚・第5弾（顔の絵8枚）の受け取り結果（2026-10-23）

■ 第4弾：10種すべて使った
・対戦の情報箱の枠 → 左の「相手（えんじ）／あなた（紺）」の箱（四隅を固定して伸ばす）
・手番の帯 → 対戦の上の帯（左右の飾りに文字がかからないよう内側に寄せた）
・アイコン → 情報箱のマナ・山札・手札。捨て札のアイコンは今の画面に捨て札の数が無いので、置いただけ（assets/images/ui/battle/icon_discard.webp）
・未入手カードの影 → 図鑑の「？」の所
・パックの販売機 → ガチャの画面の上（それまでのプログラムで描いた箱と「仮の見た目」の注記をやめた）
・主人公を選ぶ画面の背景 → そのまま
・場所の絵3枚 → ショップ・大会受付・図鑑の、顔と吹き出しの後ろ
・スティック → 歩くときの台の輪とつまみ（走るときはつまみを金色寄りに）
・ボスのしるし → ダンジョンのボス
・景品の光の輪 → 大会の景品（勝ち＝勲章・負け＝金貨）と宝箱の中身の窓

■ 第5弾：顔の絵8枚（最初の ZIP は壊れていたので、修正版 Seimon_Faces_FIXED を使った）
・研究員 → 図鑑の画面の上（ショップの店員と同じ形。吹き出しは登録数）
・練習場の先生 → 練習テーブルの会話。それまでの地の文「練習テーブルだ。練習試合をしてみる？」を、先生の仮の台詞
  「練習試合をしていくかい？ 相手ならいつでも用意してあるよ。」に変えた（正式な台詞は未定）
・大会の対戦相手6人 → 大会の勝ち抜き表と、対戦の相手の欄（名前は「仮の対戦相手（…）」のまま。人物像は Claude の仮の案）
