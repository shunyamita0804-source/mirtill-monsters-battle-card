画像01は足の形の手本です。
・A＝正面・左足を前　・B＝左向き・左足を前　・C＝斜め前・右足を前（採用済み。画像03と同じ）
新しい絵の足は、A と B のちょうど中間の形です。また C と対になる絵です。体の向き・傾き・歩幅・大きさは C と同じで、足と腕の左右だけが入れ替わります。

【いちばん大事なこと：足をねじらない】
・腰・おなか・両ひざ・両方のつま先は、全部、画像02の顔と同じ左下を向ける。ひざとつま先は同じ方向
・左足（画面の右側の足）を前に出す。左下へまっすぐ出し、手前（画面の下のほう）に着地。つま先も左下
・右足（画面の左側の足）は体の後ろ（画面の上のほう）に残り、かかとが少し上がる。つま先も左下。左や横へ流さない
・歩幅は画像03と同じ。大またにしない。両足の間を横に広げない
・腕は体の近くで前後に軽く振る（右腕を少し前、左腕を少し後ろ）。外に開かない

うまくいかないとき：
・また足がねじれた →「腰・ひざ・両方のつま先を全部左下へ。C と対の形にして、足の左右だけ入れ替えて」
・前の足が右へ出た →「前の足（左足）は左下へまっすぐ。右へは出さない」
・後ろの足が左へ流れた →「後ろの足（右足）は体の後ろ、画面の上のほうに残す。左へは出さない」
・人物が変わった →「画像02とまったく同じ人物に。変えるのは足と腕だけ」
