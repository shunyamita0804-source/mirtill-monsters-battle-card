デザイン第2弾10枚の受け取り結果（2026-10-23）

10種すべてゲームに入れた（作業ブランチ。公開はユーザーの「公開して」のあと）。比較の画像はチャットで送付。
・ダンジョンの床・壁の上面 → ダンジョンの地図。160px（4マス）ごとに敷き、マスの位置でずらして続けて見せる（world.css）。
  見分けやすさのため、床は少し明るく、壁の上面は暗く色を重ねた
・壁の正面 → 壁の下が通れるマスのとき、壁のマスの下 32px に帯を重ねる（上下の端の床・上面の描き込みは切り落とした）
・階段 → 「B3Fへ」などの階段のマスに、下り・上りの絵（文字の札はそのまま残す）
・魔物のしるし → 「敵」の赤い丸の代わり。ボスは同じ絵を大きく、金色にふち取り
・ダンジョンの対戦の背景 → ダンジョンの全部の階の対戦。それまでのミスモンの野外の背景は assets に残してある（戻せる）
・勝ち・負けの帯 → 対戦の結果の文字の後ろ（引き分けは負けの帯）
・ランクの紋章 → ベッドの画面の「ランク」（紋章の真ん中に文字）。部品は src/ui/components/rankBadge.ts（ほかの画面にも使える）
・街の上の札と丸いボタン → 場所の名前の札・上の小さなボタン・「調べる」ボタン
・パックを開けるときの光 → パックを開けた画面の背景
