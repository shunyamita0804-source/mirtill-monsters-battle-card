【組み込み担当向け】
歩行画像は横3コマ。各コマのキャンバスは512×1024。
切り出し位置：x=0 / 512 / 1024、y=0、幅512、高さ1024。
意図した並び：立つ → 右足を前 → 左足を前。
背面の足の並びは正面との対応を見て並べ替え済み。横向きは上記の要調整事項を優先。
4コマ化：0 → 1 → 0 → 2。
右向き：左向きを左右反転（元依頼どおり）。小物の左右も反転する。
216×288の実行用コマにする際は、縦横比を保って縮小し、透明余白で調整する。512×1024を216×288へ直接引き伸ばさない。
足元・頭頂を目安にサイズを調整済みだが、身体中心と接地位置は実機の歩行で再調整する。
当たり判定・原点・アニメーション速度はゲーム側で設定する。
