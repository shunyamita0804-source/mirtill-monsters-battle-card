# ミルティルモンスターズバトルカード

**ミルティルモンスターズ**シリーズのスマートフォン向け 2D カードゲームです。

> 第2段階（スマホ向けゲーム基盤構築）実装済み・承認待ち。タイトル／街／カードショップ／カードバトルの4画面を仮素材で表示できます。戦闘ルールは未実装です。

## 技術構成

- TypeScript
- Vite
- Vitest
- GitHub / GitHub Pages 対応構成（**未公開**）

## はじめかた

```bash
npm ci
npm run dev
```

詳しくは [docs/setup.md](docs/setup.md) を参照してください。
