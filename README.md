# ミルティルモンスターズバトルカード

**ミルティルモンスターズ**シリーズのスマートフォン向け 2D カードゲームです。

> 現在は **第1段階（開発環境構築）** です。ゲーム本体はまだ実装していません。

## 技術構成

- TypeScript
- Vite
- Vitest
- GitHub / GitHub Pages 対応構成（**未公開**）

## はじめかた

```bash
npm install
npm run dev
```

詳しくは [docs/setup.md](docs/setup.md) を参照してください。
